# Froloff

Вёрстка лендинга **Froloff** — морской коллаген в желе-стиках и витаминные комплексы — под перенос на **1С-Битрикс**.

Цель — качественный современный лендинг: точное соответствие макетам, плавные анимации появления, быстрая загрузка (Google PageSpeed: LCP / CLS), доступность и чистая компонентная структура, которую легко разложить по шаблонам и инфоблокам Битрикса.

> **Дальше — интернет-магазин.** Сейчас это одностраничный лендинг, но позже на его базе планируется полноценный интернет-магазин. Поэтому товары, каталог и тексты хранятся как данные (а не зашиты в разметку), а повторяющиеся элементы — отдельные компоненты, которые переиспользуются на будущих страницах (каталог, карточка товара, корзина, оформление заказа).

## Возможности

- **Адаптивность** — макеты 1920 / 1440 / 768 / 375, корректно до 360px; между 1440 и 1920 размеры меняются плавно (`mix.fluid()`).
- **Анимации** — GSAP + ScrollTrigger: каждый блок анимируется, только когда попадает в экран; при `prefers-reduced-motion: reduce` анимаций нет. Параллакс от мыши (`data-attract`).
- **Скорость** — ленивая загрузка всех изображений (lozad), предзагрузка шрифтов первого экрана, размеры у картинок (нет сдвигов вёрстки), анимируются только `transform` / `opacity` / `filter`.
- **Каталог** — карточки товаров с раскрытием по наведению (десктоп) и модалкой «Где купить» со ссылками на Ozon / Wildberries / Яндекс Маркет.
- **Форма заказа** — проверка полей, маска телефона, свой выпадающий список на устройствах с мышью (на телефонах — системный), окно об успешной отправке.
- **Доступность** — семантическая разметка, ARIA у табов, аккордеона, меню и модалок, управление с клавиатуры.

## Перенос на 1С-Битрикс

- Секции и общие блоки → шаблон сайта (`header.php` / `footer.php`) и включаемые области.
- Повторяющиеся элементы (карточки товаров, слайды, пункты состава, шаги, вопросы FAQ, сертификаты) — отдельные компоненты-макросы, которые блоки выводят циклом по массиву данных → в Битриксе цикл по `$arResult["ITEMS"]` в шаблоне `news.list` / `catalog.section`.
- Данные: `src/data/home.njk` (контент лендинга) → инфоблоки и их свойства; `src/data/site.njk` (меню, контакты, CTA, тексты модалок) → `bitrix:menu` и `bitrix:main.include`.
- Пути к ассетам относительные (`./assets/...`) → `SITE_TEMPLATE_PATH`.
- **Текст из админки:** контейнеру с текстом из визуального редактора достаточно добавить атрибут `data-editor` — заголовки, абзацы, списки, ссылки, цитаты, картинки и таблицы оформятся в стиле сайта без классов (стили — `src/scss/core/editor.scss`, демо — `ui-kit.html#editor`).
- Форма заказа: сейчас окно «Ваша заявка принята!» открывается после проверки на клиенте — в Битриксе после ответа сервера.
- У секции с формой и её обёрток не ставить `overflow: hidden` — выпадающий список рисуется поверх соседних секций.

### Сделать при натяжке / после неё

- [ ] **Картинки:** WebP/AVIF через `<picture>`, `srcset` (2–3 размера) для товаров. Самые тяжёлые сейчас: `vitamins/inositol-1200.png` (2,8 МБ), `reviews/reviews-sticks.png` (1,3 МБ), PNG карточек каталога (300–575 КБ каждая).
- [ ] **SEO в `<head>`:** `description`, Open Graph, `canonical`, `theme-color`, иконка для iOS, микроразметка Product / Organization (через `SetPageProperty` и вывод в шаблоне).
- [ ] **Заглушки → реальный контент:** фото всех вкусов и витаминов (сейчас одно на все), сертификаты, ссылки Max / WhatsApp / политики конфиденциальности (сейчас `#`), реквизиты в подвале.
- [ ] **Продакшн:** исключить стили UI kit (`blocks/general/ui-kit`) из CSS, не выкладывать `index.html` и `ui-kit.html`.

Подробное описание компонентов, анимаций и правил вёрстки — в [`AGENTS.md`](AGENTS.md).

## Установка

Требуется [Node.js](https://nodejs.org/) (версия — в `.nvmrc`) и npm.

```sh
npm install
```

## Команды

```sh
npm run dev              # сервер разработки: http://localhost:3000, сборка в temp/, живая перезагрузка
npm run build            # продакшн-сборка в build/ (минификация CSS/JS, оптимизация изображений)
```

> `npm run build` начинает с очистки — удаляет и `build/`, и `temp/`. Если dev-сервер запущен, после сборки перезапустите его.

**Качество кода:**

```sh
npm run check            # все проверки: ESLint + Stylelint + Prettier
npm run fix              # автоисправление всего, что можно
npm run lint             # ESLint (JS) + Stylelint (SCSS)
npm run format:fix       # форматирование Prettier (перед коммитом)
```

**Дополнительно:**

```sh
npm run validate         # проверка HTML из build/ валидатором W3C (сначала npm run build)
npm run analyze          # размер минифицированного JS-бандла
npm run compress         # пережать исходные изображения в src/assets/images (заменяет оригиналы!)
gulp clean               # удалить temp/ и build/
```

## Структура проекта

```
froloff/
├── src/
│   ├── assets/               # шрифты (woff2), иконка сайта, изображения (content/ — контент, system/ — декор и логотипы)
│   ├── blocks/
│   │   ├── common/           # секции лендинга и страницы 404
│   │   └── general/          # шапка, подвал, meta, шапка секции, UI kit
│   ├── components/
│   │   ├── common/           # компоненты проекта: карточки, слайды, пункты, модалки «Где купить» / «Заявка принята»
│   │   └── general/          # общие: кнопка, стрелка слайдера, табы, аккордеон, поле формы, модалка, прелоадер, меню…
│   ├── data/                 # данные: site.njk (общие), home.njk (контент лендинга)
│   ├── layouts/default.njk   # общий макет страницы
│   ├── pages/                # страницы: home, 404, ui-kit, index
│   ├── scss/
│   │   ├── core/             # переменные (токены), брейкпоинты, миксины, шрифты, типографика, глобальные стили
│   │   └── index.scss        # точка входа стилей
│   └── js/
│       ├── utils/            # reveal (анимации появления), attract (параллакс), scroll-direction, slider
│       └── index.js          # точка входа JS, инициализация компонентов
├── gulpfile.js               # сборка (Gulp + esbuild + Sass + Nunjucks)
├── AGENTS.md                 # подробное руководство по проекту
└── README.md
```

Каждый блок/компонент — папка с файлами `имя.njk` (макрос), `имя.scss` и при необходимости `имя.js` (функция `имя(context = document)` из массива `components` в `src/js/index.js`; `window.reinit()` — повторная инициализация после AJAX).

## Технологии

- **[Gulp](https://gulpjs.com/)**, **[Nunjucks](https://mozilla.github.io/nunjucks/)**, **[Sass](https://sass-lang.com/)**, **[esbuild](https://esbuild.github.io/)**, **[BrowserSync](https://browsersync.io/)** — сборка и шаблоны
- **[ESLint](https://eslint.org/)**, **[Stylelint](https://stylelint.io/)** (сортировка свойств), **[Prettier](https://prettier.io/)** — контроль качества

Библиотеки на сайте (только то, что реально используется — каждый килобайт JS влияет на PageSpeed):

- **[GSAP](https://gsap.com/)** + ScrollTrigger — анимации появления, прелоадер, параллакс
- **[Swiper](https://swiperjs.com/)** — слайдеры
- **[Fancyapps UI](https://fancyapps.com/)** — модальные окна и галерея сертификатов
- **[Lozad.js](https://apoorv.pro/lozad.js/)** — ленивая загрузка изображений
- **[IMask](https://imask.js.org/)** — маска телефона
